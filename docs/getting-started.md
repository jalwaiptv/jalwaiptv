# Getting Started with JalwaIPTV

This guide covers the basic steps to prepare a compatible device for an IPTV subscription.

## 1. Check Your Device

Before setup, confirm that your device supports a compatible streaming application. Common device categories include:

- Smart TVs
- Android TV and Google TV devices
- Amazon Fire TV and Firestick
- Android phones and tablets
- Computers and other compatible streaming devices

## 2. Check Your Internet Connection

Streaming quality depends on the stability of your connection as well as available bandwidth. If possible, use Ethernet or a strong Wi-Fi connection and avoid heavy downloads while testing playback.

## 3. Choose a Compatible Application

Application availability differs by device and app store. Install a reputable application that supports the connection format supplied with your subscription.

Only install software from sources you trust. Review an application's permissions and publisher before installation.

## 4. Enter Your Subscription Information

After receiving your subscription details, enter them only into the appropriate fields of your chosen compatible application.

Do not post subscription credentials publicly or share them in GitHub issues.

## 5. Test Playback

Test several streams and allow the application time to load its data. If playback is unstable, see the [Buffering Troubleshooting Guide](buffering-troubleshooting.md).
