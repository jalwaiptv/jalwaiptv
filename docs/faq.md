# Frequently Asked Questions

## What is IPTV?

IPTV stands for Internet Protocol Television. It describes television or video delivery using IP-based networks rather than traditional terrestrial, satellite, or cable-only delivery methods.

## Which devices can be used?

Compatibility depends on the application and subscription configuration. Common platforms include Smart TVs, Android TV, Google TV, Amazon Fire TV / Firestick, phones, tablets, and computers.

## Do I need fast internet?

Streaming requires a sufficiently stable connection. Required bandwidth varies with video quality, network conditions, application behavior, and other devices using the same connection.

## Why does streaming buffer?

Possible causes include weak Wi-Fi, congestion, device limitations, application issues, internet routing, or temporary service problems. See the [Buffering Troubleshooting Guide](buffering-troubleshooting.md).

## Can I share my login details?

Subscription credentials should be treated as private. Do not publish them in GitHub issues, forums, screenshots, or public messages.

## Is every application compatible?

No. Application support varies by platform, operating system, region, and connection format. Check compatibility before relying on a particular application.
