# Smart TV Setup Guide

Smart TV setup varies by manufacturer, operating system, country, and model. Application availability may therefore differ between televisions.

## Basic Setup

1. Connect the television to a stable internet connection.
2. Install the latest television firmware available from the manufacturer.
3. Open the television's official app store.
4. Search for a reputable compatible streaming application.
5. Install and open the application.
6. Add the subscription information supplied for your account using a connection method supported by that application.
7. Allow the application to finish loading and test playback.

## Samsung and LG TVs

Samsung and LG televisions use their own application ecosystems. A particular application may be available on one model or region but unavailable on another. Check the television's official app store rather than assuming compatibility.

## Improving Stability

Ethernet can provide a more consistent connection than Wi-Fi. If Ethernet is unavailable, keep the television within good range of the router and minimize network congestion.
