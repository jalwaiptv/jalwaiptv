# Fire TV and Firestick Setup Guide

Amazon Fire TV devices can run compatible streaming applications. Exact installation steps depend on the application you choose and its current availability in the Amazon Appstore.

## Basic Setup

1. Connect the Fire TV device to your television and internet connection.
2. Install all available Fire OS updates.
3. Open the Amazon Appstore.
4. Search for a reputable compatible IPTV or media application.
5. Install and open the application.
6. Enter the subscription information supplied for your account using the application's supported login method.
7. Allow the application to finish loading before testing playback.

## Playback Tips

- Prefer a stable 5 GHz Wi-Fi or Ethernet connection when available.
- Restart the Fire TV device and router if playback suddenly becomes unstable.
- Keep Fire OS and the streaming application updated.
- Close unnecessary applications if the device is low on memory.
- Avoid sharing subscription credentials publicly.

## Application Availability

Applications can be added to or removed from app stores over time. Use reputable applications and trusted distribution sources. Do not disable device security protections simply to install unknown software.
