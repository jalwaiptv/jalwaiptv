## Supported Device Guides

The documentation covers common environments including Smart TVs, Android TV devices, Amazon Fire TV / Firestick, phones, tablets, and other compatible streaming devices.

Compatibility can vary by device model, operating system, application, region, and subscription configuration. Check the current information on the official website before purchasing or configuring a service.

## Security

Never publish passwords, subscription credentials, API keys, server credentials, customer information, payment information, database backups, or administrative configuration in a public GitHub issue or repository.

For account-specific assistance, use the support options provided on the official JalwaIPTV website.

## Content and Rights

Users are responsible for complying with applicable laws, service terms, and content-access requirements in their location. Availability can vary by region and subscription.
